# Ohm's Law Calculator

## 日本語

### 制作目的

電気回路で学んだオームの法則を題材に、KotlinとJetpack Composeの基礎を学ぶために、制作している。

### 現在の状態

**2026/09/12**

初期プロジェクトを作成し、画面の構成を考えた。

### 実装予定

1. 電圧・電流・抵抗の計算
2. 入力値のチェックとエラー表示
3. 入力内容のクリア
4. 計算処理の単体テスト

### 使用技術

1. Kotlin
2. Jetpack Compose
3. Android Studio
